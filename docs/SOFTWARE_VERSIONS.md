# Software versions

The verified revision environment used:

- Python 3.13.3
- NumPy 2.3.4
- pandas 2.3.3
- SciPy 1.16.1
- statsmodels 0.14.5
- Matplotlib 3.10.7
- MATLAB R2025b for the historical/semi-manual preprocessing stage

Additional public-package dependencies are limited to packages imported by the retained code or tests: pingouin, Pillow, CairoSVG, pytest, and the pinned runtime dependencies in `environment/requirements-lock.txt`.
